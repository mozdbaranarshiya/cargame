# بازی ماشین — شهر آزاد

بازی سه‌بعدی فارسی و راست‌به‌چپ با گاراژ انتخاب خودرو، شهر گسترده، ترافیک، سکه، سوخت و حساب کاربری. تمام کتابخانه‌های مرورگر و فونت داخل مخزن هستند؛ پس از دریافت مخزن، اجرای برنامه به CDN یا اینترنت نیاز ندارد.

## اجرا

به **Node.js 24** یا جدیدتر نیاز است؛ نسخهٔ بررسی‌شده در `.node-version` ثبت شده است. از داخل مخزن اجرا کنید:

```sh
npm start
```

سرور روی پورت `8000` و تمام رابط‌های شبکه اجرا می‌شود. برای پورت دیگر از `PORT=8080 npm start` استفاده کنید. هیچ وابستگی زمان اجرا نیاز به نصب ندارد. برای توسعه از همین checkout استفاده کنید؛ محیط ابری از قبل جداست و به Git worktree جدید نیاز ندارد.

باز کردن مستقیم `index.html` یا اجرای وب‌سرور Python برای حساب‌ها و ماژول‌های برنامه کافی نیست؛ سرور Node را اجرا کنید.

## گاراژ و رانندگی

بازی ابتدا منو را نشان می‌دهد. خودرو را انتخاب کنید و دکمهٔ شروع را بزنید. سقف سرعت خودروها به ترتیب ۱۰۰، ۱۶۰، ۲۲۰، ۳۰۰، ۴۰۰ و ۵۰۰ کیلومتر بر ساعت است؛ سطح مسیر و شتاب بر سرعت واقعی اثر دارند. سکه‌های کل در منو حفظ می‌شوند. راهنما در منو قرار دارد.

| کلید | عملکرد |
| --- | --- |
| W / ↑ | گاز |
| S / ↓ | ترمز و دنده‌عقب |
| A / ← و D / → | فرمان |
| Space | ترمز دستی و دریفت |
| H | بوق |
| Q / E | راهنمای چپ / راست |
| L | چراغ جلو |
| F | سوخت‌گیری، وقتی نزدیک پمپ بنزین و متوقف هستید |
| C | تغییر دوربین |
| M | قطع یا وصل صدا |
| R | بازگرداندن خودرو به محل شروع |
| Escape | بازگشت به منو |

روی موبایل، دکمه‌های لمسی رانندگی و امکانات خودرو در دسترس هستند. صدا پس از اولین تعامل کاربر فعال می‌شود؛ بلندی صدا از منو قابل تنظیم است. خاموش بودن صدای دستگاه یا محدودیت مرورگر همچنان اثر دارد.

## کاربران و اطلاعات ذخیره‌شده

ثبت‌نام شامل نام، نام خانوادگی، شماره موبایل، جنسیت (مرد یا زن)، نام نمایشی و رمز عبور حداقل ۸ نویسه است. ورود با شماره موبایل و رمز عبور انجام می‌شود. شماره‌های فارسی و عربی نیز پذیرفته می‌شوند. شماره موبایل شناسهٔ ورود است؛ تأیید پیامکی و بازیابی رمز در این نسخه پیاده نشده است.

مهمان هم می‌تواند بازی کند. امتیاز و سکهٔ مهمان در همان مرورگر ذخیره می‌شوند؛ حساب‌ها روی سرور در SQLite ذخیره می‌شوند. داده‌های سرور در `data/game.sqlite` و فایل‌های journal آن قرار دارند و در Git ثبت نمی‌شوند. `DATABASE_PATH` امکان انتخاب محل دیگر را می‌دهد. هنگام تهیهٔ نسخهٔ پشتیبان، سرور را متوقف کنید و کل پوشهٔ داده را نگه دارید یا از ابزار سازگار با SQLite backup استفاده کنید.

امتیازهای حساب از بازی مرورگر دریافت می‌شوند و ارسال تکراری با شناسهٔ درخواست دوباره محاسبه نمی‌شود. این بازی تک‌نفره است؛ امتیازها در برابر دستکاری یک مرورگرِ تحت کنترل کاربر، اعتبار رقابتی ندارند.

## پنل مدیریت

مدیر رمز پیش‌فرض ندارد. مالک سرور باید یک‌بار حساب مدیر بسازد:

```sh
npm run admin:create -- --username myadmin
```

رمز و تکرار آن در ترمینال بدون نمایش دریافت می‌شود. رمز را در کد، Git یا آرگومان خط فرمان قرار ندهید. سپس مسیر `/admin` را باز کنید و با همان نام کاربری و رمز وارد شوید. فقط مدیر احراز هویت‌شده می‌تواند فهرست کاربران، شماره موبایل، امتیاز و سکه‌های آن‌ها را ببیند. اطلاعات مدیر جدا از حساب بازیکنان ذخیره می‌شود و رمزها با scrypt هش می‌شوند.

برای شبکهٔ محلی، اگر دستگاهِ میزبان واقعاً آدرس `192.168.43.175` دارد و فایروال اجازه می‌دهد، پنل از `http://192.168.43.175:8000/admin` در دسترس است. این آدرس خصوصی از اینترنت یا محیط ابری خودبه‌خود قابل دسترسی نیست. تمام آدرس‌ها برای ورود مدیریت نیاز به رمز دارند؛ IP به‌تنهایی مجوز مدیریت نمی‌دهد.

برای استقرار عمومی، HTTPS را روی reverse proxy خود فعال کنید و متغیرهای زیر را تنظیم کنید:

- `PUBLIC_ORIGIN`: مبدا عمومی کامل برنامه، برای مثال `https://game.example.com`.
- `SECURE_COOKIE=1`: ارسال کوکی نشست فقط روی HTTPS.
- `PORT`: پورت داخلی سرور (پیش‌فرض ۸۰۰۰).
- `DATABASE_PATH`: مسیر خصوصی فایل پایگاه داده (پیش‌فرض `data/game.sqlite`).

برنامه محدودیت تلاش ورود، کوکی نشست HttpOnly/SameSite، بررسی مبدا درخواست‌های تغییردهنده و SQL پارامتری دارد. پوشهٔ داده، کد سرور و فایل‌های مخفی از وب سرو نمی‌شوند.

## بررسی و ساختار

```sh
npm test
```

آزمون‌های API با پایگاه دادهٔ موقت اجرا می‌شوند. آزمون مرورگر با Playwright و Chromium به‌صورت جداگانه اجرا می‌شود؛ اگر Playwright توسط محیط فراهم شده است:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright npm run test:browser
```

اسکریپت مرورگر سرور و پایگاه دادهٔ موقت خودش را می‌سازد و داده‌های واقعی را تغییر نمی‌دهد. برای نصب اختیاری ابزار آزمون در سیستم شخصی می‌توان Playwright را بدون ثبت در وابستگی‌های برنامه نصب کرد؛ خود بازی به آن نیاز ندارد.

- `server/`: پایگاه داده، رمزها، API و ساخت حساب مدیر.
- `scripts/ui.js`: گاراژ، فرم‌ها، حساب، پنل مدیریت و ذخیرهٔ پیشرفت.
- `scripts/cars.js`: تعریف مشترک خودروها و سرعت‌ها.
- `scripts/game/`: صحنه، خودرو، شهر، صدا و منطق رانندگی.
- `game.js`: ورود به ماژول بازی و مدیریت خطای شروع.
- `vendor/`: Three.js و فونت محلی همراه مجوزها.

فرایندهای زنده پس از بازسازی محیط ادامه پیدا نمی‌کنند؛ در هر کار تازه دوباره `npm start` را اجرا کنید. انتشار مخزن یا استقرار عمومی باید جداگانه انجام شود.
